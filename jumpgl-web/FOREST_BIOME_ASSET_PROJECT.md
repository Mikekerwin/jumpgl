# Forest Biome Asset Project

## Visual Target

`forest-art-workbench/source/reference.png` is the primary visual target for the
prairie-to-forest transition and repeating forest biome.

## First Extraction Pass

The reproducible extraction pipeline is in `../tools/forest_assets/`.

Current workbench output:

| Source | Extracted assets | Intended use |
| --- | ---: | --- |
| `background.png` | 87 | Far-background trees, trunks, foliage, vines, and details |
| `middleground.png` | 62 | Midground trees, branch platforms, trunks, roots, and props |
| `mid.png` | 5 | Large foreground/midground playable trees |
| `singleTreeExplode.png` | 81 | Modular foreground tree construction and branch platforms |
| `reference.png` catalog | 47 | Supplemental transition, ground, and atmosphere pieces |
| `custom.png` | 14 | Foreground tree compositions requiring additional cleanup |

Total: 296 transparent first-pass assets.

Open `forest-art-workbench/catalog.html` to inspect the generated contact sheets.

## Quality Notes

- White-background JPEG sheets extract cleanly with soft transparent edges.
- Some closely spaced source objects remain useful grouped compositions.
- `custom.png` contains dark composite regions and transparency artifacts; its
  strongest tree designs need a dedicated cleanup/reconstruction pass.
- The workbench is intentionally outside `public/`. Only selected and optimized
  runtime assets should be added to the game.

## Proposed Runtime Layers

1. Far forest silhouettes with a cool blue tint and slow parallax.
2. Background tall trunks and canopy clusters.
3. Midground trees, roots, and foliage.
4. Playable foreground trees and branch platforms with explicit hitboxes.
5. Frontmost roots, leaves, and vines for depth.

## Next Stage

Curate the strongest assets into layer-specific sets, clean the selected custom
foreground trees, optimize them to WebP/PNG, and build a standalone forest
composition preview before connecting the biome to gameplay.

## WebGL Sandbox

The standalone PixiJS WebGL tester is available at:

```text
http://127.0.0.1:5173/jumpgl/forest-sandbox.html
```

It intentionally does not use the live game scene. The sandbox:

- Preloads a curated 14 MB runtime set of 66 optimized WebP textures.
- Reuses cached GPU textures instead of loading the full extraction workbench.
- Scrolls ground and six visual layers at different parallax speeds.
- Recycles 90 scene objects as they leave the screen.
- Builds foreground trees from interchangeable bases, trunk sections, canopies,
  branch platforms, and detail pieces.
- Includes a fixed white ball as a player-scale reference.

Controls:

- Speed slider: adjust horizontal scroll speed.
- Space: pause/resume.
- R: rebuild the randomized composition.
- F: fullscreen.

The runtime assets are generated by
`../tools/forest_assets/prepare_sandbox_assets.py`. The full extraction
workbench remains outside `public/`; only the curated sandbox set is shipped to
the browser.
